## Overview

Finite Labs Essentials is a set of utility drivers that fill gaps in Control4
programming. Each driver works on its own, so a project installs only the ones
it needs.

## Features

- Sensor Aggregator: several temperature, humidity or contact sensors combined
  into one reading
- Sensor Multiplexer: one of several named groups of sensors passed through,
  picked from programming
- Device Programmer: virtual sensors and relays that programming sets
- Light Relay: relay devices controlled from a light switch, with their state
  kept in step
- Variable Expressions: text and math built from variables, each result its own
  variable and event
- Network Requests: HTTP, TCP, UDP and Wake-on-LAN commands to devices with no
  Control4 driver, sent from programming
- Composer tabs to write expressions and requests, with a live preview

## System requirements

- Control4 OS 3.3+
