# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with
code in this repository.

Six independent Control4 DriverWorks drivers built on one shared library:
`sensor_aggregator`, `sensor_multiplexer`, `device_programmer`, `light_relay`,
`variable_expressions`, `network_requests`. Each builds for two distributions
selected by preprocessor directives: `oss` (self-updates from GitHub releases)
and `drivercentral` (DriverCentral cloud licensing).

`README.md` describes what each driver does. `CONTRIBUTING.md` documents the
layout, the toolchain and the build pipeline. This file holds what neither says.

## Most of this repo is not editable here

This project is generated by [Copier](https://copier.readthedocs.io/) from
`finitelabs/control4-driver-template`; `.copier-answers.yml` pins the version.
**`Makefile`, `src/lib/*.lua`, `vendor/`, `tools/`, `test/`, `CONTRIBUTING.md`,
`.gitignore` and `LICENSE` are template-managed. Editing them here works locally
and is then silently reverted by the next `copier update`.** Fix those in the
template repo, tag it, then run `copier update`. `CONTRIBUTING.md` carries the
authoritative list.

Editable here: `drivers/*/`, `src/constants.lua`, `documentation/`,
`CHANGELOG.md`.

## Build

The toolchain is Python and Make. There is no Node, no npm, and no
`package.json`.

```bash
make init          # One-time: venv, Python tooling, clones driverpackager
make build         # clean-build fmt preprocess gen-squishy update-xml docs package zip
make build-nodocs  # Same, skipping doc generation
make fmt           # stylua (Lua), black (Python), mdformat --wrap 80 (Markdown)
make help          # Every target
```

`make clean` removes `build/` and `dist/`. Only `make clean-all` also removes
the venv.

**Adding a driver needs no registration step.** Every build target globs
`build/<dist>/drivers/*/`, so creating the directory is enough.

**`squishy` is generated, not written.** `make gen-squishy` loads each
`driver.lua` under `test/c4_shim.lua`, reads `package.loaded`, and emits the
module list per distribution. No `squishy` exists under `drivers/`, and
hand-writing one is wrong.

Copy `drivers/sensor_aggregator/` when starting a driver. It is guaranteed
current in a way a template pasted into this file is not.

## Traps

- **`CLOSED`/`OPENED` fire programming events; `STATE_CLOSED`/`STATE_OPENED` set
  the same state silently.** Pick between them on `gInitialized` (false in
  `OnDriverInit`, true at the end of `OnDriverLateInit`). Restoring bindings on
  boot with the wrong pair replays every automation the driver has ever
  triggered.
- **`C4:AddEvent` is unavailable before `OnDriverLateInit`,** so
  `events:restoreEvents()` must be called from there, never from `OnDriverInit`.
- **`OPC.*` and `OVC[]` keys replace spaces with underscores.** A property shown
  as `Log Mode` is `OPC.Log_Mode`, and `values.lua:ovcKey()` does the same to
  variable names. A handler registered under the display name silently never
  fires.
- **`getOrAddDynamicBinding(namespace, key, type, provider, ...)` takes
  `provider` as a required positional boolean.** There is no output-by-default;
  omitting it passes `nil`.
- **Binding type drives the ID range.** `CONTROL` (temperature, humidity)
  allocates 10-999; `PROXY` (contact sensors) allocates 5012-5999. A contact
  sensor is a `PROXY` despite not sounding like one.
- **`utils.lua` exports `SerializeSafe`/`DeserializeSafe`.** Bare
  `Serialize`/`Deserialize` are different functions, from
  `vendor/drivers-common-public/global/lib.lua`.
- **`lib/transform.lua` and `lib/expressions.lua` are adapted from
  `control4-influxdb`.** Extend both sides together or they drift.
- **Do not assume a library is distribution-guarded because it looks optional.**
  In `network_requests`, `require("lib.http")` sits outside the
  `--#ifndef DRIVERCENTRAL` block that wraps `github-updater`, so `http.lua`
  ships in DriverCentral builds too. Read the guard rather than inferring it.

## Conventions

- Preprocessor directives are `--#ifdef` / `--#ifndef` / `--#else` /
  `--#endif DRIVERCENTRAL` in Lua, and `<!-- #ifdef ... -->` in XML and
  Markdown. Generated squishy files carry no conditionals.
- Handler tables are keyed as Control4 expects: `OPC.Property_Name`,
  `EC.CommandName`, `GCPL.Command_Name`, `RFP[bindingId]`, `OBC[bindingId]`,
  `TC[conditionalName]`, `OVC[variableName]`.
- All dynamic state persists through `lib/persist.lua` and is restored by
  `bindings:restoreBindings()`, `values:restoreValues()` and
  `events:restoreEvents()`.
- `C4`, `Properties` and `Variables` are Control4 runtime globals;
  language-server warnings about them are expected.
